#Sports Data Processing & Automation
A framework for structuring, cleaning, and processing raw sports event data for analytical pipelines.
Core Modules
**Data Cleaning:** Automated removal of duplicates and normalization of athletic metrics.
**Dataset Structuring:** Formatting raw match feeds into clean analytical tables.
**Metric Automation:** Auto-calculating aggregate season stats and performance indicators.
Tech Stack
**Languages & Tools:** Python (Pandas), SQL, Excel
**Focus:** Data Engineering, Automated Reporting
